## 1. Catalog of Generated Figures

The figures cataloged below were generated by [`scripts/plot_results.py`](file:///scripts/plot_results.py) directly from empirical benchmark datasets in `results/`. Both web-ready 300 DPI PNGs and lossless vector PDFs are available:

### Figure 1: Small-Message Latency Comparison vs. Danyliuk (2026)
- **Files:** [`results/plots/fig1_danyliuk_comparison.png`](file:///results/plots/fig1_danyliuk_comparison.png) | [`results/plots/fig1_danyliuk_comparison.pdf`](file:///results/plots/fig1_danyliuk_comparison.pdf)
- **Data Source:** `results/baseline_1m_64b.csv` & `results/fas_ipc_results.csv` compared with Danyliuk (2026) Table 1.
- **Description:** Grouped bar chart comparing one-way response times across the 64 B to 1024 B small-message spectrum. Highlights that FAS-IPC (196.17 ns at 64B) outperforms Danyliuk's 850 ns benchmark by **$4.33\times$** and beats classical Pipes and Sockets by **$7.4\times$**.

### Figure 2: Empirical 2D Crossover Contour Map
- **Files:** [`results/plots/fig2_crossover_map.png`](file:///results/plots/fig2_crossover_map.png) | [`results/plots/fig2_crossover_map.pdf`](file:///results/plots/fig2_crossover_map.pdf)
- **Data Source:** `results/matrix_results.csv` & dynamic crossover thresholds.
- **Description:** Two-dimensional empirical contour map delineating optimal transport selection zones across Message Size (64 B to 1 MB, log scale) and Message Arrival Rate (100 to 1,000,000 msg/s, log scale):
  - **Zone 1 (Emerald Green):** FAS-IPC Fast Path ($\le 1024$ B).
  - **Zone 2 (Deep Blue):** Linux Anonymous Pipe Streaming ($1024\text{ B} - 64\text{ KB}$).
  - **Zone 3 (Rust Orange):** UNIX Domain Socket Streaming ($> 64\text{ KB}$).

### Figure 3: Tail Latency Cumulative Distribution Function (CDF)
- **Files:** [`results/plots/fig3_tail_latency_cdf.png`](file:///results/plots/fig3_tail_latency_cdf.png) | [`results/plots/fig3_tail_latency_cdf.pdf`](file:///results/plots/fig3_tail_latency_cdf.pdf)
- **Data Source:** `results/matrix_results.csv` percentile columns (Min, P50, P90, P99, P99.9).
- **Description:** Cumulative distribution function curves plotted on a semi-log scale. Demonstrates that while classical OS primitives flare out into severe scheduler tail spikes (P99.9 exceeding 13–88 μs), FAS-IPC and Adaptive A-IPC maintain tightly bounded tail latencies under **584 nanoseconds** at P99.9.

### Figure 4: Adaptation Gain & Latency Reduction on Dynamic Mixed Workloads
- **Files:** [`results/plots/fig4_adaptation_gain.png`](file:///results/plots/fig4_adaptation_gain.png) | [`results/plots/fig4_adaptation_gain.pdf`](file:///results/plots/fig4_adaptation_gain.pdf)
- **Data Source:** `results/mixed_workload_gain.csv` (80% 64 B + 20% 16 KB mixed workload).
- **Description:** Dual-panel performance validation chart:
  - **Left Panel (Throughput):** Shows Adaptive A-IPC delivering 536,143 msg/s, almost doubling Static Socket (284,909 msg/s) to achieve **$G_{\text{adapt}} = 1.88\times$**.
  - **Right Panel (Latency Reduction):** Shows a **46.86% latency reduction** over the best static baseline, while static shared memory drops packets.
